# Changelog

## 0.2.0 — 2026-10-30

- Добавлен поиск точных фраз с использованием позиций терминов.
- Добавлен префиксный поиск через суффикс `*`.
- Добавлен оператор исключения `NOT`.
- Добавлена HTML-безопасная подсветка совпадений.
- Расширен набор автоматических проверок поискового ядра.

## 0.1.0 — 2026-10-01

- Индексирование и поиск по нескольким полям.
- Ранжирование BM25, операторы `AND` и `OR`.
- Обновление, удаление и сохранение документов.
- HTTP API на ASP.NET Core.
